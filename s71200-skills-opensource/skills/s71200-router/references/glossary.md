## 1. 存储器与访问模型

| 术语 | 手册中的实际用法 | 页码 |
|---|---|---|
| 装载存储器（Load memory） | 非易失存储用户程序/数据/组态；程序＋数据日志＋配方＋Web 页面共享同一块预算，算错即下载失败 | 76–77、31–33、394–407 |
| 工作存储器（Work memory） | 易失、执行程序时用；活动配方数据块必须在这里，Web 页面不占这里 | 76–77、31、384 |
| 保持性存储器 | 存"限量的工作存储器值"；下载不清除它；M 区只能从 MB0 起连续保留，优化型 FB/全局 DB 才能逐变量设 Retain | 77–79 |
| 优化块访问 / 标准访问 | 必须配对的二值属性：不配对 → HMI/中断 OB 对 IN/OUT 的写入静默丢失；PEEK、Serialize 缓冲区要求标准访问 | 158–161、78–79、207 |
| 过程映像分区 PIP0–PIP4 | 决定 I/O 在哪个时机更新；分给 PIP1–4 却不配 OB = 永不更新（等价 None），不是"慢一拍" | 59–61、127 |
| 立即读/立即写（`:P` 访问） | 直接读写物理点绕过过程映像；`I_:P` 只读；`I` 无法强制、只能强制 `:P` | 83–84、961–967 |
| 传值 / 传引用 | 优化设置不配对时 STRUCT 的传引用被暗中降级为传值（副本→回写→丢中断/HMI 改写） | 160–161 |
| 数据一致性 | 跨 OB 共享一组值必须用 DIS_AIRT/EN_AIRT 成对包裹；通信指令同样有"作业完成后才可改"的一致性窗口 | 162–163、547 |
| 嵌套深度 | 从循环/启动 OB 算 16 层、从中断 OB 算 6 层、安全程序 4 层；无推导的设计决定 | 155 |
| 多重背景 | 把实例存进调用块接口而非独立背景 DB；决定定时器/计数器数据能否在 RUN-STOP-RUN 后保持 | 182–188 |
| M_BIT / R_TRIG-F_TRIG | 沿指令前状态的两族载体：P/N 用存储器位（必须独占不复用），R_TRIG/F_TRIG 用背景 DB 位；首次扫描也评估 | 182–184 |
| IEC_TIMER | 每个定时器是 16 字节的 IEC_Timer DB 结构；数量仅受存储器容量限制（推翻"定时器只有 T0–T255"的旧直觉） | 184–188 |
| 系统存储器 / 时钟存储器 | FirstScan 等系统位与时钟位各占一个 M 字节；可被指令或通信覆盖且不报错——是保留区不是只读区 | 78–81 |
| GEOADDR / 硬件标识符 | GEO2LOG/LOG2GEO/IO2MOD/RD_ADDR 在"过程映像地址/HW_IO/插槽"三类地址间换算，硬件重排不改程序 | 422–427 |
| 组态时间 / 比较预设与实际组态 | 组态时间超时后 CPU 照常进 RUN（静默降级）；兼容性判据是"功能可以更多，但不能更少" | 125–127 |

## 2. 通信

| 术语 | 手册中的实际用法 | 页码 |
|---|---|---|
| 连接 ID / 动态资源 | "预留＋34 个动态资源"两池模型；加 CM/CP 不增加连接总数；HMI 每台实际占 1–3 个资源（5 台可吃满 12 个预留） | 477–479 |
| TSAP | OUC 连接端点标识（ISO-on-TCP 层），不是 TCP 端口；填错表现为超时而非明确报错 | 477–479、510–541 |
| 特殊模式（S7 通信） | 为与 S7-300/400 对齐而偏离默认行为的兼容开关（LEN=65535 等）；PROFIBUS 上 GET/PUT 可能被强制单向 | 634–644 |
| 共享设备 | 一个物理 IO 设备的子模块被两个控制器分别分配，访问权必须互补；STEP 7 不检测错误 | 593–599 |
| 智能设备（I-device） | 一个 CPU 作 IO 设备向上级控制器交出传送区；与共享设备方向相反（是"把自己交出去"） | 591–606 |
| 看门狗时间 / 重新组态时间（MRP） | 环网重组硬约束 200 ms，看门狗必须大于它（按周期数表述）；S7-1200 无需组态环网端口 | 612–615 |
| 轮询架构（PtP/RTU/USS） | 串行收发没有后台自动，必须用户程序循环调用；PtP 从站"OB 循环时间内 Receive 两次"才不丢帧 | 793–794、891–893 |
| 消息开始条件 / 结束条件（PtP） | 开始条件之间是 AND、结束条件之间是 OR；响应超时不是结束条件，须另配一个真正的结束条件 | 765–770 |
| N / LENGTHSIZE / LENGTHM | 报文自述长度的三参数：n 从 1 起计、长度大小只取 1/2/4、m＝长度字段之后不参与计数的尾字符数 | 770 |
| Send_P2P / Receive_P2P | DONE/ERROR 只保持一个周期且须同背景 DB 再执行才刷新；每接口缓冲 1024 字节 FIFO；BUFFER 不支持 Bool | 784–788 |
| PtP 自由口参数两层覆盖 | 设备组态持久、Port_Config/Send_Config/Receive_Config 仅 RUN 有效（STOP/掉电即复原）；RS485 不支持流控制 | 759–765 |
| 3964(R) 协议 | STX/DLE/ETX/BCC/NAK 五字符成帧，与自由口报文条件互斥；协议行为详述外链 CP 341 手册 | 759–760、772 |
| 新旧两代 PtP 指令 | Send_P2P/Receive_P2P 与 SEND_PTP/RCV_PTP 并存且旧指令"无须转换"；"全大写＝老一代"是全书命名潜规则 | 759、900–901 |
| USS_Port_Scan 与 LINE_PRE | 每端口一个、同网络同端口的所有 USS 功能共用同一背景 DB；CB 1241 上 LINE_PRE 默认 2 必须手工改 0（否则 16#81AB） | 804 |
| USS_Drive_Control | 它本身不通信（真正收发在 Port_Scan）；输出是上一轮响应；改 DRIVE 号要 STOP→RUN；OFF2/OFF3 低有效（为假才停机） | 802–806 |

## 3. Web

|---|---|---|

| AWP 注释空格 / 转义规则 | 注释内空格缺失→编译器静默不生成正确代码且不报错（手册自认）；反斜杠是转义字符；页面须 UTF-8 保存 | 721、732 |

| 入口页（AWP1） | "AWP1/起始页面"二选一下拉框；生效需三前置：WWW 指令被调用＋用户权限＋CPU 处于 RUN | 733–734 |
| Web 用户/角色双模型 | V4.7 及以上走 UMAC，低于 V4.7 走逐用户访问级别＋默认无密码 Everybody；两份权限清单无法逐项对应，迁移须人工重映射 | 682–686 |
| 多语言页面（siemens_automation_language） | 六语言文件夹取子集；cookie 必须由页面 JS 设置且 path=/；HTML 目录指向语言文件夹的上级而非某一语言 | 746–749 |
| Web 访问容量（30/7/50） | 30 个活动连接（与每页对象数相关）、7 个同时登录、Web API 50 个并发会话——三个数字三种口径，须并列引用 | 678、695、752–753 |
| 仅允许 HTTPS 访问 | ⚠ p732 称"默认设置"与 p753 的 http/https 并列描述冲突——须显式确认勾选，不能当默认事实 | 732、753 |
| Web API（S7-1500 子集） | 14 个方法（Api.*/PlcProgram.*/Syslog.Browse）；LWord/LInt/LTime_Of_Day/S5Time/LDT 不支持；完整文档外链 | 752 |
| Recipes/DataLogs/UserFiles 目录 | 三套子系统（Web/数据日志/文件指令/TMAIL）共用的目录约定；任何登录权限都不能删 Recipes/DataLogs 文件夹；UserFiles 不允许子文件夹 | 715–717、556、428–430 |

## 4. Modbus

| 术语 | 手册中的实际用法 | 页码 |
|---|---|---|
| MB_CLIENT / MB_SERVER | 都走 CPU 自带 PROFINET 端口、不需要额外通信模块；TCON_IP_v4 的 LocalPort/RemotePort 与 ActiveEstablished 两端恰好互换，填反即超时 | 817–828 |
| MB_MODE | 0＝标准寻址（带区号 5 位地址）、1xx＝扩展寻址（0–65535）；与 MB_DATA_ADDR 共同决定功能码；扩展寻址最大数据长度减 1 | 817–820、876–880 |
| MB_UNIT_ID / MB_ADDR | TCP 不用 Unit ID 寻址（默认 255，仅为 RTU 网关转发保留）；RTU 值 0 保留广播且仅 4 个功能码可广播；TCP 无广播 | 822、876–877 |
| MB_DATA_PTR / MB_HOLD_REG | 指针载体分层约束：结构必须未优化 DB；基本类型＋指令版本 ≥V4.0 可启用优化；M 区缓冲用 P# 格式 | 817–821、824–826、877–880 |
| HR_Start_Offset | 把保持寄存器基址从 40001 重定位（双向约束，同时抬高禁止区）；⚠ 表 14-69 数字排版粘连，以正文算例 40021/40120 为准 | 828–830 |
| Data_Area_Array | 最多 8 区域把 Modbus 地址映射到 DB；第一个空条目终止搜索（1,2,4,5 只生效 1,2）；目标 DB 必须关优化＋关"仅装载存储器"；定义后接管该类型（越界报 8383） | 830–832 |
| 保持寄存器与过程映像映射 | 功能 1/2/4/5/15 直落过程映像、3/6/16 走 MB_HOLD_REG；QB/IB_Count 默认 65535＝全开——可读写范围即安全边界 | 826–828 |
| Modbus RTU 三代指令 | Comm_Load（组态）→Master/Slave（轮询，同端口共用同一背景 DB）；Master 禁止在启动/诊断/时间错误 OB 执行；RETRIES 默认 2（0x80C8＝重试耗尽） | 876–893 |
| 单侧 / 双侧冗余 | 连接名＝〈S7 连接点〉〈伙伴节点〉（0A/1A/0B/1B）；谁冗余决定拓扑，两侧都自认冗余会组出无效结构；需付费授权 | 833–841 |
| REG_KEY / IDENT_CODE / LICENSED | 三步闭环：跑指令取 18 位 IDENT_CODE→申请 17 位 REG_KEY→填回；缺授权仍通信但 STATUS_x 恒 0A90、ERROR LED 闪烁、诊断缓冲区循环刷条目 | 833–834、863–866 |

## 5. 安全

| 术语 | 手册中的实际用法 | 页码 |
|---|---|---|
| UMAC（用户管理与访问控制） | 用户/角色/功能权限三层本地管理（42 用户/14 组/20 角色上限）；默认启用；必须下载 CPU 才生效；与访问等级不必同开 | 135–141、682–686 |
| 访问等级 | 标准 CPU 四档，默认"无访问权（完全保护）"；密码保护不约束指令执行与 PLC 间通信；读访问可改 RUN/STOP；紧急 IP 不受限 | 138–141 |
| Anonymous 用户 | ⚠ 手册最尖锐内部矛盾：安全警告"请勿激活"（p138/139）vs PUT/GET 三步第①条"启用 Anonymous"（p141），无取舍说明 | 137–141 |
| 安全向导 | 四部分＋总览；"完成"只存进项目、必须下载 CPU 才生效；"取消"全部丢弃 | 132–133 |
| 三类块保护 | 专有技术保护防读代码（局部变量隐藏但调用结构仍可读）、写保护防误改、复制保护防他机运行（不含 DB）；复制保护密码与专有技术密码是两个密码 | 146–148 |
| 保护机密的 PLC 组态数据 | 密码不匹配则无法下载；存储卡三件套 SET_PWD/SET_PWD.S7S/PWD.TXT 可离线设置，空 PWD.TXT＝清除密码 | 106–108、133–134 |
| ENDIS_PW / F_PWD | 运行期四条密码独立开关；标准 CPU 上 F_PWD 必须恒置 1；上电后失效须重执行；立即禁止会锁死 TIA Portal（须定时器延迟） | 245–247 |
| 证书限值 64 与参数矩阵 | Web＋OPC UA＋OUC 共享 64 个系统证书池（CA 链各占一位、自签名不可下载）；只有 RSA 2048 四服务全支持；RSA 4096 吃掉至少 60% 扫描周期负载 | 479、691 |

## 6. 诊断

| 术语 | 手册中的实际用法 | 页码 |
|---|---|---|
| 诊断缓冲区 | 多子系统共同输出汇聚点（故障/安全事件/许可证循环条目/组态不匹配）；块内 GET_ERROR 处理会让该块错误不再进缓冲区 | 958–959、81、864、250 |
| 三灯状态判据 | STOP/RUN、ERROR、MAINT 组合判状态；MAINT 常亮可能是"强制 I/O 未清"；禁用诊断时 I/O 错误显示绿灯 | 945–947 |
| Defect / Fatal | 三态之外的第四态、连服务数据都取不出；重启成功＝三灯持续闪烁且无法下载，失败＝STOP＋ERROR 亮、MAINT 灭 | 948、955–956 |
| ErrorStruct / GET_ERROR 反向语义 | ENO=TRUE 表示发生了错误（语义反转）；REACTION 三值按写/读/系统三分；MODE 决定后续地址字段如何解析 | 248–251 |
| 模拟量诊断值 32767 的多义性 | 上溢/断路（<1.185 mA）/电源故障（所有通道）/未启用诊断都报 32767；只报第一个错误，清除此因后才报下一个 | 947–948 |
| Error_Decode / DPV1 STATUS | 解码分层＝责任方→错误码→制造商；GSD rev3＋"S7 兼容"模式下槽号偏移＋3；INDEX 负值被重解释为无符号；并发上限 4＋4 | 299–301 |
| RUN 模式下载 | 不停机改程序的官方手段：一次 ≤20 块＋副效应清单＋12 条可能临时失败的指令；"下载而不重新初始化"扩 DB 保运行数据 | 968–975 |
| 轨迹功能 | 抓难复现间歇性问题的唯一工具；组态细节外链 STEP 7 信息系统；且轨迹属存储卡损耗源之一 | 975–977、106 |
| 备份 / 恢复（两套） | Web 服务器备份与 STEP 7 备份不互通；硬前提 PROFINET 直连（不支持 CM 的 PROFIBUS 口）；恢复中断可永久丢保护等级 | 711–712、979–983 |
| 强制的持久性 | 强制值存在 CPU 而非监视表：关 STEP 7 仍生效；HSC/PWM/PTO 占用的点无法强制；调试收尾必须清强制 | 961–967 |

## 7. 容量

| 术语 | 手册中的实际用法 | 页码 |
|---|---|---|
| 活动配方数据块 | 双 DB 架构：配方数据块在装载存储器（全部配方），活动配方块在工作存储器（当前一条）；READ_DBL/WRIT_DBL 是两存储层间的搬运工 | 384–394 |
| 数据日志字节口径 | 每次写入至少占 2 KB、仅占装载存储器、最多同时打开 8 个；读卡器删文件不释放 CPU 持久内存；掉电可能丢当前记录（同页两说 ⚠） | 395–400 |
| READ_DBL / WRIT_DBL 保持性扩充 | 用装载存储器归档不常变的保持性数据以扩充 14 KB 限制；REQ 必须上升沿；频繁调用损耗闪存并挤占通信资源 | 418–420 |
| 存储卡寿命与不可安全擦除 | 五类循环写入点名为损耗源（含轨迹与 SET-TimeZone）；S7-1200 不支持安全擦除；用 Windows 格式化程序即报废该卡 | 106–107 |
| ATTR_DB 与 DB_LENGTH=0 | 运行期读 DB 属性的唯一入口；DB_LENGTH=0 是"优化访问或仅位于装载存储器"（多义，非空块）；运动控制 DB 禁查（80B2） | 420 |
