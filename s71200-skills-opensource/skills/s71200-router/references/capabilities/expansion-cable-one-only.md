# 能力卡：每个 CPU 系统只允许一条扩展电缆

## R（原文引用）
> "S7-1200 扩展电缆可用来更灵活地组态 S7-1200 系统的布局。每个 CPU 系统只允许使用一条扩展电缆。可以将扩展电缆安装在 CPU 和第一个 SM 之间，或者安装在任意两个 SM 之间。"
> ——《S7-1200 系统手册》V4.7，5.3.7 安装和卸下扩展电缆，p52

## I（自述）
I/O 扩展电缆（2 m，订货号 6ES7290-6AA30-0XA0，p1150 表 A-266）用于把系统布局拉开，但**每个 CPU 系统全系统只能用一条**——不能在多个模块间隙各塞一条。可插位置只有两类：CPU 与第一个 SM 之间、任意两个 SM 之间。安装纪律：全程断电操作；母连接器的锁定小接头必须完全滑到位才算啮合；振动环境用扎带做应力消除（p53）。

## A1（合成演练，含可复算数值）
原书未提供数值算例。合成演练：CPU + 8 SM，机柜布局要求 CPU 与第 4 个 SM 之间拉远、第 7 与第 8 之间也拉远 → 需要两条电缆 → 违反"每系统一条"。可行解：只保留一处拉远（选影响布局最大的一处），另一处用紧凑排布或换柜体布局。

## A2（未来触发）
- 场景：机柜布局设计问"能不能多接几条延长"；安装评审；模块间隙规划。
- 语言信号：中"扩展电缆能用几条／延长模块间距／6ES7290"；英"expansion cable count / one expansion cable only"。
- 相邻区分：模块数量上限 → max-modules-limits；功率预算（电缆不影响功率，但要计入布局）→ power-budget-precheck；本卡只回答"几条、装哪"。

## E（执行步骤）
1. 输入契约：系统模块清单 + 拟拉远位置清单。
2. 判定：拟用电缆数 ≤1？位置 ∈ {CPU↔第一 SM, SM↔SM}？
3. 超限处置：保留一处拉远或改布局，不得双电缆。
4. 安装检查（p52–53）：断电、母接头锁定小接头滑到位、振动环境扎带固定。
5. 完成标准：布局图标注唯一电缆位置 + 安装三查通过。

## B（边界）
- 反场景：想延长 PROFINET 通信距离（那是网线/交换机问题，CSM 1277 p1151）；信号板/电池板位置（CPU 顶部，无电缆延长）。
- 手册口径：电缆 2 m、200 g（p1150）；拉拽避免用力过猛（p53）。
- 矛盾/勘误：无。
- 外链缺口：无。
