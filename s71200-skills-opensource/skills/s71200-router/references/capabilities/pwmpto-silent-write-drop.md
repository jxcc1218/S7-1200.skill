# 能力卡：PWM/PTO 输出地址静默丢弃且不可强制 + 频率/时基静默边界

## R（原文引用）
> "说明：用户程序中的其它指令无法使用脉冲发生器输出。将 CPU 或信号板的输出组态为脉冲发生器时（与 PWM 或运动控制 PTO 指令配合使用），会从 Q 存储器中移除相应的输出地址，并且这些地址在用户程序中不能用于其它用途。如果用户程序向用作脉冲发生器的输出写入值，则 CPU 不会将该值写入到物理输出。"（p379）
> "说明：上表中给出了每个 CPU 和信号板输出的最小循环时间。但是，当所组态 PWM 脉冲发生器的循环时间小于此硬件的最短循环时间时，TIA Portal 并不会提醒用户。您的应用可能因此会出现问题，因而请务必确保不会超出硬件限制。"（p381）
> ——《S7-1200 系统手册》V4.7，10.8 脉冲

## I（自述）
PWM/PTO 域有三类静默失败：①**写 Q 地址被静默丢弃**——组态为脉冲发生器的输出点已从 Q 存储器移除，程序向该 Q 地址写值 CPU 不写物理输出、不报错；同时这些点**不可强制**（监控表强制无效，p967 同口径）。②**循环时间低于硬件最短值 TIA 不提醒**——如 CPU 输出最短 PWM 循环 10 µs（1217C DQa.0–DQa.3 为 1 µs，p381 表 10-192），组态小于该值时静默出问题。③**脉宽小于 1 个时基输出直接关断**——ms 时基脉宽须 ≥1 ms、µs 时基须 ≥1 µs，小于则输出关闭（p381 例：10 µs 周期 × 5% = 0.5 µs < 1 µs → 关断）。

## A1（书中算例 + 合成演练）
书中算例（p381）：周期 10 µs、占空 5% → 脉宽 0.5 µs < 1 µs（时基）→ PWM 信号关闭。另一组（p382–383）：ms 时基、周期 3 ms、初值 75% → 脉宽 2.25 ms 为小数 → CTRL_PWM 报错（脉宽必须整数）；改 µs 时基周期 3000 µs × 75% = 2250 µs 整数 → 正常。合成演练：程序写 Q0.0（已组态 PWM1）→ 物理输出不变且无错误——自查时先查输出点是否被脉冲发生器占用。

## A2（未来触发）
- 场景："PWM 输出不生效/改占空比没反应"；调低循环时间后波形异常；强制脉冲输出点失败。
- 语言信号：中"PWM 写不进去／脉宽被关断／循环时间太短／强制不了 Q0.0"；英"PWM output address ignored / pulse width below time base / cannot force PWM output"。
- 相邻区分：HSC 点不可强制 → hsc-chaos 卡 B 段（同 p967 原理，HSC 域）；PTO 频率修改时序（当前脉冲结束才切换，p378）属 PTO 行为域；硬件组态步骤 → router。

## E（执行步骤）
1. 输入契约：输出点号 + 现象（无输出/值不变/强制失败）。
2. 查设备组态：该点是否已分配给 PWM/PTO（含默认地址 QW1000–1006 脉宽寄存器区域，p383）。
3. 若被占用：脉宽修改必须走 Q 字（QW1000 等）而非普通写；普通 Q 写一律无效。
4. 边界复算：循环时间 ≥ 硬件最短值（表 10-192/10-193）；脉宽 = 初值% × 周期 ≥ 1 时基单位且为整数。
5. 静默失败自查：无错误码时，先验"点被占用"与"脉宽<1 时基"两条，再查 CTRL_PWM STATUS（80A1=标识符无效）。
6. 完成标准：示波器/驱动器侧确认物理输出随 QW 值变化。

## B（边界）
- 反场景：普通数字量输出不动作（非脉冲域，查接线/组态）；运动控制 PTO 工艺对象（另域）。
- 手册口径：脉宽精度还要考虑输出通道开关延迟（p382"实际脉宽可能大于选择的值"）——高频小脉宽影响更大。
- 矛盾/勘误：无（A23 自动协商矛盾与脉冲域无关）。
- 外链缺口：运动控制方向/定位 → 运动控制手册（D1）。
