# 能力卡：D_ACT_DP 80A1/80A6 部分失败伪装成 W#16#0000 成功

## R（原文引用）
> "80A1 无法为寻址的组件分配参数。（仅当 MODE = 1 时，才可能出现该错误代码。）注：如果所激活的设备进行参数分配时，该组件再次发生故障，则 D_ACT_DP 指令将返回该错误信息。如果某个模块参数分配失败，则 D_ACT_DP 将返回错误信息 W#16#0000。"（p310）
> "80A6 PROFINET IO 设备中的插槽错误；无法访问所有用户数据……如果仅一个单个模块不可用，D_ACT_DP 返回错误信息 W#16#0000。"（p310）
> ——《S7-1200 系统手册》V4.7，10.3.7 D_ACT_DP

## I（自述）
D_ACT_DP（启用/禁用 PROFINET IO 设备）在 MODE=1（激活）时有两个"部分失败"陷阱：激活作业整体返回 W#16#0000（成功），但设备内部某个模块参数分配失败（80A1 场景）或单个模块不可用/插槽错误（80A6 场景）——**部分失败被 0000 伪装成完全成功**。只看 RET_VAL 会误判。补救通道：部分失败的信息走设备诊断（GET_DIAG/诊断缓冲区/诊断报警），不在 RET_VAL 里。适用域：OEM 选装配置（用 MODE=1/2 激活/取消激活选装设备，p308 示例）。

## A1（合成演练，含可复算数值）
原书未提供数值算例。合成演练：激活带 4 个模块的 IO 设备，其中模块 3 参数分配失败。D_ACT_DP MODE=1 → RET_VAL=0000、BUSY=0（看似成功）。验证链：立即对设备 LADDR 调 GET_DIAG / 等诊断中断 → 发现模块级"参数分配错误"条目。处置：纠正模块组态/重插，再 MODE=1 重激活。

## A2（未来触发）
- 场景：OEM 选装机器激活后"个别模块不工作但指令说成功"；D_ACT_DP 结果审计。
- 语言信号：中"D_ACT_DP 返回 0 但模块坏了／80A1／80A6／激活部分失败"；英"D_ACT_DP RET_VAL 0000 partial failure / 80A1 parameterization"。
- 相邻区分：80A7（激活超时、设备不可达，状态仍"已激活"）是**显式报错**不是伪装，p310/311；MODE=0 查询状态（0001 已启用/0002 已取消激活）是正常查询语义。

## E（执行步骤）
1. 输入契约：作业 MODE 与设备 LADDR。
2. 判停（防御性规则）：MODE=1 且 RET_VAL=0000 时**不得**直接宣布成功——必须追加设备级诊断确认。
3. 确认链：GET_DIAG（站/模块）或诊断缓冲区；发现 80A1/80A6 对应的模块级条目 → 处理该模块。
4. 作业取消：激活进行中要中止 → LADDR+MODE=2 重复调用直至 RET_VAL=0（p309 说明）。
5. 完成标准：RET_VAL=0000 **且** 模块级诊断无新错误，两者同时满足才算激活成功。

## B（边界）
- 反场景：MODE=0 状态查询；禁用作业（MODE=2，替代值输出/过程映像置 0，p309）；网关（IE/PB Link）不支持（8093）。
- 手册口径（p309）：取消激活后的设备"错误 LED 不会将其识别为故障或丢失"，且过程映像输入更新为 0——复电排查时注意这是设计行为。
- 矛盾/勘误（Z2 已核）：80A1/80A6 注释精确位于 p310；引用页码不要写成 p307–311 全段。
- 外链缺口：无（错误码表手册自足）。
