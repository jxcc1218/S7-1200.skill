# 能力卡：RTD 电阻量程满量程换算与『无传感器=32767』判据

## R（原文引用）
> "上溢：32767 RTD 输入；下溢：-32768；断路：32767 电阻输入"（p947 模拟量模块诊断表）
> "热电偶/RTD：'热电偶'：将度数乘 10 得到该值（例如，25.3 度将报告为十进制数 253）。'电压'：额定范围的满量程值将是十进制数 27648。"（p1088）
> ——《S7-1200 系统手册》V4.7，15.2 模拟量模块诊断 / A.12 技术规范

## I（自述）
RTD 域两个判定/换算口径：①**32767 判据**——RTD 通道上溢=32767、下溢=−32768、断路=32767（p947 表），与热电偶同口径；读到 32767 至少两义（上溢/断线），区分靠诊断/读数符号背景。②**满量程换算**——温度类"度数×10"（0.1 °C 分辨率，253=25.3 °C）；电压类满量程=27648。RTD 与 TC 的选型表、精度、3/4 线制接线另见附录 A.12（p1093–1096 SM RTD 表，其中 A6 矛盾见 B 段）。本卡承接 32767 框架卡在 RTD 子域的取数口径。

## A1（合成演练，含可复算数值）
原书未提供 RTD 数值算例（TC 表 p1091 有官方换算示例）。合成演练：Pt100 读数 1234 → 温度 =1234/10 = 123.4 °C（度数×10 规则）。反向： Pt100 在 850 °C 上限之上 → 上溢 32767。B16 类错误示范（不得复现）：若某选型表上下限颠倒（上限−145 < 下限−120），以物理量程常识与同族表交叉校验，不照抄。

## A2（未来触发）
- 场景："RTD 读到 32767 是断线还是超量程"；把 RTD 原始值换算温度；RTD 选型查量程。
- 语言信号：中"RTD 32767／铂电阻读数换算／0.1 度分辨率"；英"RTD 32767 wire break / multiply by ten / 0.1 C resolution"。
- 相邻区分：**四义总判别**（上溢/上电未就绪/断路/模块级）→ 32767-ambiguity-resolution（晋级卡，本卡只给 RTD 域取数与换算）；报文级判别 → ainfo-26-33 卡；热电偶 6 秒断路测试 → thermocouple 卡。

## E（执行步骤）
1. 输入契约：模块型号（SM/SB 1231 RTD）+ 原始读数 + 接线制式。
2. 值判读：32767 → 上溢或断路（以诊断启用状态与背景区分，p947）；−32768 → 下溢。
3. 换算：温度值 ÷10 = °C；确认所选 RTD 类型的额定范围表（p1093+）。
4. 标定衔接：27648 口径与 NORM_X/SCALE_X 的对接 → analog-scaling-27648（晋级卡）。
5. 完成标准：读数→工程量的换算式与出处（p1088）落地。

## B（边界）
- 反场景：电流/电压模拟量（走 27648 标定卡）；热电偶断路测试时序（→thermocouple 卡）。
- 矛盾/勘误（A6 取舍判据）：RTD 超范围最大值 SM 版写 +32767（p1096）、SB 版写 +32768（p1132，越出 Int 范围）——取舍：**以 SM 版 +32767 为准**（与 p947 诊断表、Int 上限自洽），SB 版 32768 判为笔误，引用时标注。
- 外链缺口：SB 1231 RTD 选型表 B16（Pt100 气候型上下限颠倒）与 B17（50 Hz 3 线更新时间 1.086 s 破坏规律，应为 0.132）——引用 SB RTD 表必须逐值复核，不得整表照抄。
