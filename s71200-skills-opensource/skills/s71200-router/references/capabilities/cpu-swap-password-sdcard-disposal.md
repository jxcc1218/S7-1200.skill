# 能力卡：更换 CPU 密码/存储卡处置六规则（含免复位两分支）

## R（原文引用）
> "更换部件方案的规则：……如果可能，请使用没有项目组态或已组态密码（保护机密的 PLC 组态数据）的 CPU 作为更换 CPU。优势：将项目下载到更换 CPU 中，无需进行任何其它准备工作。如果已组态更换 CPU，则必须将 CPU 复位为出厂设置，并选择以下选项：删除保护机密 PLC 组态数据的密码；如果 CPU 具有存储卡，则格式化存储卡。"（p1166）
> "如果未向项目中的 CPU 分配……密码，则可以将旧 CPU 的存储卡插入到全新未使用的 CPU 中，而无需采取任何其它操作。"（p1166）
> ——《S7-1200 系统手册》V4.7，D.1 更换用于保护机密组态数据的 CPU

## I（自述）
换 CPU 的处置由两条轴决定：更换件是否已组态密码 × 项目是否启动机密数据密码。六规则要点：①首选"无组态/未组密码"的更换件（零准备）；②已组态更换件 → 复位出厂+勾选"删除保护密码"+格式化存储卡；③项目未启用密码 → 旧卡可直插全新未用 CPU；④更换件已组密码 → 必须先复位清密码；⑤同组 CPU 用**相同密码**时，可经设备组态把组密码分给更换件，旧卡直插免复位；⑥逐 CPU **不同密码**时，转在线用"设置保护机密 PLC 组态数据的密码"给替换件设密（p1166）。密码设置/删除的在线操作前提：设备组态为"在设备上直接设 IP"（p954）。

## A1（合成演练，含可复算数值）
原书未提供数值算例。合成演练：项目启用密码、旧 CPU 带程序卡损坏。选择：更换件是同组同密码 CPU → 走规则⑤：设备组态分配组密码 → 插旧卡上电即可用，免复位；更换件是陌生旧机（已组密码）→ 走规则②：复位出厂（勾删除密码+格式化卡）→ 下载项目。两条分支处置不同、不可混用。

## A2（未来触发）
- 场景：CPU 损坏采购备件；换件后"密码不匹配无法下载/转 RUN"；安全清场。
- 语言信号：中"换 CPU 要注意什么／更换件有密码／旧卡能不能直接插"；英"CPU replacement password / confidential PLC configuration data / swap SD card"。
- 相邻区分：固件代际更换（V3.0→V4.x）→ v3-v4-migration（本卡同版本更换，那卡跨版本）；丢密码找回 → password-loss-blank-card-erase；V3 传送卡不兼容（p1168）归迁移卡。

## E（执行步骤）
1. 输入契约：项目是否启用机密数据密码；更换件状态（新机/旧机、有无组态密码、有无卡）；密码策略（无/同组同密/逐机异密）。
2. 三分支判定：a) 无密码项目 → 旧卡直插新机（或直接下载）；b) 同组同密 → 分配组密码后直插；c) 其他 → 复位出厂（删除密码+格式化卡）→ 设密/下载。
3. 执行复位（p954 六步，勾选对应复选框）或在线设密（p953）。
4. 验证：下载项目、CPU 转 RUN、机密数据访问正常。
5. 完成标准：更换后 CPU 在线可用且密码策略与项目一致。

## B（边界）
- 反场景：跨固件大版本（→migration 卡）；只想找回密码不想换件（→password-loss 卡）。
- 手册口径：在线设密/删密的工具前提="IP address is set directly at the device"（p954）——组态口径不符时在线功能不可用。
- 矛盾/勘误：无；C-939/C-319（复位后果）并入本卡路由。
- 外链缺口：无。
