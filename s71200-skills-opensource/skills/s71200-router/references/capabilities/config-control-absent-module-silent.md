# 能力卡：组态控制『不存在』模块的静默剖面（读 0 / 写无效 / 无诊断）

## R（原文引用）
> "如果已在控制数据记录中将模块组态为丢失（0 个条目），则自动化系统会按如下方式运行：在控制数据记录中被标识为不存在的模块不会提供诊断并且它们的状态始终为正常。值状态正常。对不存在的输出量的直接写访问或对不存在的输出量的过程映像的写访问将不产生任何影响；CPU 不会报告任何访问错误。对不存在的输入量的直接读访问或对不存在的输入量的过程映像的读访问将为每个输入生成一个'0'值；CPU 不会报告任何访问错误。"
> ——《S7-1200 系统手册》V4.7，7.4 组态控制『运行期间的特性』，p121

## I（自述）
组态控制（控制数据记录 196）把某插槽标为"不存在"（Slot 值=0）后，该模块进入静默剖面：①无诊断、状态恒"正常"；②写其输出（直接或过程映像）完全无效且无访问错误；③读其输入恒返回 0 且无访问错误；④写数据记录无影响；只有读数据记录才报错。这是为 OEM 选装件设计的行为（最大组态+按需隐藏），但对排障者是陷阱：模块根本没接，程序和在线视图却"一切正常"（在线/诊断按设备组态显示而非实际组态，p121）。配套硬规则：启用组态控制但无有效控制记录 → CPU 退出 STARTUP 进 STOP（p119/p121）；记录经 WRREC 写入硬件 ID 33 索引 196，只能在启动 OB 传送（错误 80E2，p122）。

## A1（合成演练，含可复算数值）
原书未提供数值算例。合成演练：最大组态 3 SM，实际未装插槽 3 的模块 → 控制记录字节：字节 0=16（块长）、1=196、2=5、3=0（标头，p120）；Slot_3 分配=0；已装模块填实际插槽号；未组态插槽=255。运行中读 %IW96（插槽 3 模块输入）→ 恒 0，无错误条目。误判预防：看到"输入恒 0 且无诊断"先查控制记录是否标 0，而不是查传感器。

## A2（未来触发）
- 场景：OEM 机型裁剪后"某模块读数全 0 无报警"；组态控制上线后在线视图与实际不符；CPU 启动直接 STOP（记录缺失/80E2）。
- 语言信号：中"组态控制／控制数据记录 196／模块标成不存在／读出来全是 0"；英"configuration control / record 196 / absent module reads zero"。
- 相邻区分：模块真坏了（有诊断条目）→ 诊断缓冲域卡；F-I/O 不支持组态控制（p121 准则，动了全报"参数分配"错误）；通信模块 101–103 必须与实际一致（禁位置更改/停用）。

## E（执行步骤）
1. 输入契约：实际安装拓扑 + 设备组态（最大组态）。
2. 生成控制记录：标头（16/196/5/0）+ 各插槽分配（0=不存在，1–9/101–103=实际位置，255=组态中无模块）。
3. 启动 OB 中 WRREC → 硬件 ID 33、索引 196，等完成（p119）。
4. 判停：CPU 转 STOP 且缓冲区提示组态控制 → 查记录是否传送/值非法（80B0/80B1/80B5/80B8，p122）。
5. 静默失败自查："输入恒 0/写无效/状态正常"三联征 → 核对该插槽在控制记录中是否为 0。
6. 完成标准：隐藏模块行为与预期一致（读 0、写忽略），非隐藏模块正常工作。

## B（边界）
- 反场景：想让"缺失模块"报错（那就不要用组态控制隐藏它）；运行时切换组态（记录修改在下次启动生效，存储器复位并采用新组态，p121）。
- 矛盾/勘误（B20/Z5 取舍）：p122 错误码表说 80B0 是"块类型（字节 2）≠196"，但 p120 记录结构字节 1=块 ID 196、字节 2=版本 5——两页自相矛盾；引用时标注口径不可依赖，判 80B0 一律以"块 ID 字段非 196"语义理解。Z5：静默剖面页码为 p121（非 p120）。
- 外链缺口：无（本条手册自足）。
