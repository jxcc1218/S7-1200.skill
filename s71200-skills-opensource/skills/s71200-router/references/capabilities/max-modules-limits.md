# 能力卡：最大 SM/CM/SB 数量与插槽上限（3 CM 对 CP 同样适用）

## R（原文引用）
> "CPU 型号 允许的最大信号模块数：1211C 0；1212C 2；1214C 8；1215C 8；1217C 8。"
> ——《S7-1200 系统手册》V4.7，附录 B，p1153

## I（自述）
型号绑定的扩展上限速查：SM 上限仅 1211C 是 0（想挂 SM 必须换 CPU），1212C 为 2，其余 8。CM 任何型号最多 3 个，且该 3 个名额对 CP 同样适用（CM/CP 共享左侧位置）。SB/CB/BB 三者合计最多 1 个。这些数字是预算计算与选型评审的第一道闸。

## A1（合成演练，含可复算数值）
原书未提供本条独立算例。合成演练：CPU 1212C + 2×SM 1223 + 1 CM = 2/2 SM ✓、1/3 CM ✓ → 合法；再加 1 个 SM → 3 > 2 ✗。CPU 1211C 任何 SM 请求直接否决（0/0）。

## A2（未来触发）
- 场景：报价/方案评审问"这个 CPU 最多能扩展几个模块"；排障发现"模块插不上/组态不进"；评估 1211C 要不要升级。
- 语言信号：中"最多几个信号模块／扩展上限／1212C 挂三个行不行"；英"max signal modules / expansion limit"。
- 相邻区分：上限过了但担心功率 → power-budget-dual-column-procedure；扩展电缆（每系统一条）→ expansion-cable-one-only；SB/CB/BB 互斥细节 → power-budget-precheck。

## E（执行步骤）
1. 输入契约：CPU 型号（1211C/1212C/1214C/1215C/1217C）。
2. 查表返回 SM 上限（0/2/8/8/8）；CM/CP 合计上限恒为 3。
3. 与实际清单比对，输出"型号 → 上限 → 当前数 → 可/不可"。
4. 完成标准：三个上限位（SM/CM+CP/板槽）都有判定。
5. 缺失信息处理：型号未知（如只给订货号）→ 先映射订货号到型号再查，不得猜。

## B（边界）
- 反场景：把上限当"功率允许"——过了上限检查仍可能超 5V 预算，两道闸都要过。
- 矛盾/勘误：无；注意"3 个 CM"与"CP 同样适用"来自 destinations 并入口径（C-1002/C-448/C-1029 三源），引用时注明。
- 外链缺口：CSM 1277、RF120C、CM CANopen 等随附产品的挂载数在 A.22（p1151–1152），不在本卡范围。
