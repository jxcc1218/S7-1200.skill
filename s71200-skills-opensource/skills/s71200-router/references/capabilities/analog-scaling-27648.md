# analog-scaling-27648 — NORM_X→SCALE_X 标定与电压型 −27648 分叉

## R — Reading（原文）

> "要将模拟值转换为对应的工程单位，应将输入标准化为 0.0 到 1.0 之间的值，然后再将其标定为 -30.0 到 70.0 之间的值。"（p239，示例 LAD：标准化和标定模拟量输入值）

> "请注意，如果模拟量输入来自电压型模拟量信号模块或信号板，则 NORM_X 指令的 MIN 值是 -27648，而不是 0。"（p239）

> "请注意，如果模拟量输出应用到电压型模拟量信号模块或信号板，则 SCALE_X 指令的 MIN 值是 -27648，而不是 0。"（p239）

> "满量程范围（数据字） 0 到 27648 过冲范围（数据字） 27649 到 32511 上溢范围（数据字） 32512 到 32767"（p1003，表 A-22 CPU 内置模拟量输入）

## I — Interpretation（自述）

模拟量换算的骨架是**两段式**：先 NORM_X 把原始值压到 0.0–1.0，再 SCALE_X 把 0.0–1.0 拉到工程量区间。公式（p238）：NORM_X 出 `OUT = (VALUE − MIN) / (MAX − MIN)`；SCALE_X 出 `OUT = VALUE × (MAX − MIN) + MIN`。真正致命的不是公式，而是**MIN 取几的分叉**：手册默认用电流型举例（有效值 0–27648），但**电压型模块的额定范围是 −27648 起的**（如 ±10 V 对应 −27648…+27648），所以 NORM_X/SCALE_X 的 MIN 必须改成 −27648。这条分叉只写在两段示例后的"请注意"里，参数表中找不到；照抄电流型参数用于电压型，结果会整体偏移约半个量程且**无任何报错**。第二个维度是方向：反向（工程量→模拟量输出）用同一对指令反着接，电压型输出同样分叉。第三个维度是判断读数性质：27648 以上依次是过冲区（27649–32511）和上溢区（32512–32767）——那是 32767 卡的领地，本卡只负责"正常值怎么换算"。

## A1 — Application Example（书中案例 + 标注演练）

**书中算例（p239，电流型）**：0–27648 ↔ −30.0…70.0 °C。NORM_X(MIN:=0, MAX:=27648) → SCALE_X(MIN:=−30.0, MAX:=70.0)。反向输出侧：SCALE_X(MIN:=0, MAX:=27648)。手册成对给出输入/输出两题，每题后紧跟"请注意"分叉句。

**【合成演练，按原书规则可复算】** 电压型输入 ±10 V，读回 Raw = 13824，求电压：
1. NORM_X(MIN:=−27648, MAX:=27648)：OUT = (13824−(−27648)) / 55296 = 41472/55296 = **0.2500**。
2. 对应电压（额定满程 10 V）：0.25 × 20 V − 10 V = **−5.0 V**。
3. **错法对照**（若误用 MIN=0）：OUT = 13824/27648 = 0.5 → 被当成 +5 V——**偏差 2 倍量程、方向错、无报错**。这就是"电流型示例是默认呈现方式，电压型照抄必错"的实证。
4. 复算口径：÷27648 比例、额定/过冲/上溢分段均取自 p1003–1004、p1085 表值；演练未引入原书外规则。

## E — Execution（可执行步骤）

**输入契约**（缺则先问，禁止静默猜）：①信号类型——**电流型还是电压型**（决定 MIN 分叉，必填）；②模块型号与量程（如 ±10 V / 0–20 mA / 4–20 mA）；③原始值 Raw（Int）或目标工程量；④工程量两端点（如 −30.0…70.0 °C）。

**计算顺序与公式**：
1. **Step 1 认类型**（判停点）：查模块测量范围表确认额定范围下限。电流型/单侧电压（0–10 V）→ MIN=0；**双极性电压（±10 V 等）→ MIN=−27648**。输出侧对称：电压型输出的 SCALE_X MIN 同样取 −27648。✅ 完成标准：MIN 取值有页码依据（p239 请注意 / 附录 A 该型号范围表）。
2. **Step 2 两段式标定**：`N = (Raw − MIN_N) / (MAX_N − MIN_N)`；`Eng = N × (MAX_E − MIN_E) + MIN_E`。**自洽检查（静默失败自查点）**：Raw=MIN_N 时 Eng 必须=MIN_E、Raw=MAX_N 时 Eng 必须=MAX_E，两端不通即参数填反；同一 Raw 用"正确 MIN"与"MIN=0"各算一次，两者差异 ≈ 半量程即中招分叉错。✅ 完成标准：两端点闭合 + 倍差检查通过。
3. **Step 3 反向（需要时）**：`N = (Eng − MIN_E)/(MAX_E − MIN_E)`；`Raw = N × (MAX_N − MIN_N) + MIN_N`，用书中反向示例复算一次闭合。
4. **Step 4 溢出定性（移交判停点）**：Raw 在 27649–32511 = 过冲（仍按比例换算但超出额定）；32512–32767 = 上溢——**移交 32767 卡**，本卡换算到此为止。

**输出契约**：一段可直接照抄的 NORM_X/SCALE_X 参数组（各参数值 + 数据类型；约定：SCALE_X 的 MIN/MAX/OUT 数据类型必须相同，NORM_X 的 MIN/VALUE/MAX 必须相同，p238 表 9-123 注）+ 一行换算结果 + 两端点闭合检验值。**容差**：手册未规定舍入——中间值保留 Real 全精度，只在最终显示层舍入；演练复算偏差 >0.1% 判参数错。

## B — Boundary（边界与失败模式）

- **反场景**：值是 32767/−32768 → 32767 卡；"通道没接传感器读多少" → 32767 卡（无传感器=32767）；模块怎么选/怎么接线 → router。
- **手册警告的失败模式（静默）**：①电压型照抄 MIN=0 → 结果偏移半量程、**无报错**（p239 两处"请注意"是全书仅有的提示）；②SCALE_X 的 VALUE 超出 0–1 时会**静默**输出超出 MIN/MAX 的值且 ENO=TRUE，只有落入类型范围外才 ENO=FALSE（p238 说明框）——上游 NORM_X 参数错会被 SCALE_X 无声吞掉；③MAX ≤ MIN 时 OUT 被最低有效部分填充（p239 表 9-124），同样是静默错值。
- **澄清清单教训（R1 类）**：任何标定规则必须**带信号类型维度**。手册的电流型示例是默认呈现，不带维度照抄＝错误规则；CPU 内置 0–10 V 单侧输入又是"MIN=0"的另一码事（p1003"负值不支持"）——**MIN 取值随具体模块型号走，不可跨型号外推**。
- **手册自足性缺口**：p238–240 未给电压型/电流型选型判定表，分叉只有两句话（验证记录 C-068 实读确认）；换算分段表在附录 A（p1003–1004、p1085–1086），正文不给。
- **相邻易混淆**：与 32767 卡抢调用的唯一风险点是"读数不对"——值域在额定范围内→本卡；值贴边（≥32512 或 =32767）→32767 卡。
