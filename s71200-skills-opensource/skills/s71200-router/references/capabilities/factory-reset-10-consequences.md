# 能力卡：复位为出厂设置三复选框决策与十项后果（MAC 不变）

## R（原文引用）
> "3. 如果要删除 IP 地址，选中'删除 IP 地址'(Delete IP address) 复选框。4. 如果要删除密码，选中'删除保护机密 PLC 组态数据的密码'……5. 如果要格式化当前插入到在线 CPU 中的存储卡，选中'格式化存储卡'(Format memory card) 复选框。……结果：模块会根据需要切换到 STOP 模式，并复位为出厂设置。在线 CPU 执行以下操作：删除工作存储器以及保持性数据区域；……将所有参数和操作数区域设置为其组态的值；清空诊断缓冲区；复位时间；删除 I&M0 之外的 I&M 数据；……根据您所做的选择，保留或删除 IP 地址。（MAC 地址固定不变。）"（p954–955）
> ——《S7-1200 系统手册》V4.7，15.9 复位为出厂设置

## I（自述）
复位为出厂（在线和诊断 > 功能 > 复位为出厂设置）的决策核心是**三个独立复选框**：删 IP、删保护密码、格式化卡——按处置目的逐项勾选，不是全勾或全不勾。执行前提：CPU 在线且 STOP（RUN 下启动会提示转 STOP）。十项后果清单（p954–955）：删工作存储器+保持性数据、删内部装载存储器（卡上装载存储器仅在勾选格式化时删）、参数回组态值、清诊断缓冲区、复位时间、删 I&M0 之外的 I&M、（未存卡时）复位运行小时计数器、IP 按选择删或留、删控制数据记录（若有）、密码按选择删或留、按选择格式化卡。**MAC 地址永远不变**——这是复位后"扩展的下载到设备"还能按 MAC 找到设备的锚点。

## A1（合成演练，含可复算数值）
原书未提供数值算例。合成演练：换件清场（项目将启用新密码、新 IP）：勾"删 IP"+“删密码”+“格式化卡”→ 十项后果逐项发生；复位后用"扩展的下载到设备"按 MAC 定位设备重新组态。对照场景：只想清程序保留网络 → 只走默认（不勾任何框）：IP 保留（除非被程序/工具改过，则恢复组态值，p955）、密码保留。

## A2（未来触发）
- 场景：设备转用途/转售前的清场；换件；"复位后 IP 怎么没了/还在"。
- 语言信号：中"复位为出厂设置／三个复选框怎么勾／MAC 会变吗"；英"reset to factory settings / delete IP / format memory card / MAC unchanged"。
- 相邻区分：不支持安全擦除的合规结论 → no-secure-erase；丢密码用空卡（无在线手段时）→ password-loss-blank-card-erase；B7 勘误（第 3 步措辞含混）见 B 段。

## E（执行步骤）
1. 输入契约：处置目的（清场/换件/清程序）+ 是否保留网络配置。
2. 前提：CPU 在线（需 IP 可达）+ STOP；设备中已分配 IP（在线功能前提，p957）。
3. 按目的勾选：三复选框逐项决策并记录理由。
4. 执行（p954 步骤 6–7：复位 PLC→确认）。
5. 后果核对：对照十项清单逐项确认（尤其"控制数据记录被删除"与"I&M 清除"易被漏估）。
6. 完成标准：复位后 CPU 处于 STOP、按 MAC 可再发现、勾选项效果与预期一致。

## B（边界）
- 反场景：只想删密码但无在线连接（用空传送卡路径）；卡上数据合规问题（→no-secure-erase）。
- 手册口径：未勾"删 IP"时保留硬件配置的 IP/掩码/路由——除非被程序或工具改过，此时恢复为修改后的值（p955）；运行小时计数器仅在"值未存卡"时复位（p955）。
- 矛盾/勘误：B7——复位步骤第 3 步措辞含混（p954），执行时以复选框语义与十项后果清单为准；订货/订货号引用注意 B11。
- 外链缺口：无。
