# 能力卡：IO-Link 主站复位出厂的后果核对与入库前置动作

## R（原文引用）
> "SM 1278 IO LINK（6ES7278-4BD32 0XB0）…… 7 针，镀锡"（p1163，端子排备件表）
> "SM1278 IO-Link 主站 6ES7278-4BD32-0XB0 FS03 或更高版本 5000 m"（p994，海拔表）
> （IO-Link 主站模块的复位出厂属 15.9 复位为出厂设置的设备域应用：复位对象含模块组态与 I&M 数据；主站端口参数与设备描述（IODD）在复位后需重新核对入库——destinations 口径：'IO-Link 主站复位出厂的后果核对与入库前置动作'）
> ——《S7-1200 系统手册》V4.7，附录 C.7 / A.3

## I（自述）
IO-Link 主站（SM 1278）执行复位出厂/格式化类清场后，工程侧的**入库前置动作**是本卡核心：①主站模块组态（端口模式、参数集）随复位丢失，须重新下载硬件组态；②下层 IO-Link 设备的参数（经主站访问的设备参数集）需按 IODD/工程备份重新下发或核对；③端子排备件（7 针镀锡，p1163）与订货号登记（注意 B10：手册中 6ES7278-4BD32 存在缺位写法）；④海拔/环境合规按 p994（FS03+，5000 m）。此域手册着墨少（IO-Link 主站细节需外部文档），本卡以"复位后果核对清单"形式兜底。

## A1（合成演练，含可复算数值）
原书未提供数值算例。合成演练：SM 1278 主站 4 端口复位出厂。核对链：端口 0–3 模式恢复默认 → 每个 IO-Link 设备重新参数化（读回设备参数与工程记录比对）→ 主站硬件组态重新下载 → 端子排/订货号台账更新（6ES7278-4BD32-0XB0，修正 B10 缺位写法）。判据：4 个端口逐一验证通信与参数一致性。

## A2（未来触发）
- 场景：IO-Link 站清场/换主站后重建；设备参数莫名回默认；备件入库登记。
- 语言信号：中"IO-Link 主站复位／SM 1278 参数丢了／IODD 重新下发"；英"IO-Link master factory reset / SM 1278 parameters lost / IODD re-parameterize"。
- 相邻区分：CPU 级复位出厂 → factory-reset-10-consequences（十项后果清单对主站模块同样构成背景约束）；换件密码处置 → cpu-swap 卡。

## E（执行步骤）
1. 输入契约：主站型号/FS 版本（≥FS03 支持高海拔，p994）+ 复位范围（CPU 级/模块级）。
2. 复位后清单：硬件组态重下载 → 端口模式逐口核对 → IO-Link 设备参数重下发（IODD）。
3. 一致性验证：读回各设备参数与工程记录比对，差异登记。
4. 台账更新：订货号（修 B10 缺位：6ES7278-4BD32-0XB0）、端子排型号、FS 版本。
5. 完成标准：4 端口通信正常且参数与工程记录一致。

## B（边界）
- 反场景：仅 CPU 复位（主站组态仍在 CPU 项目里，重下载即可恢复）；IO-Link 设备本体复位（设备厂商文档）。
- 手册诚实缺口：IO-Link 主站的端口参数细节、IODD 管理本手册不闭环——引用外部 IO-Link 文档并声明缺口。
- 矛盾/勘误：B10——p1102 订货物号"6ES 278-4BD32"缺位，应为 6ES7278-4BD32（p994/p1163 一致口径）。
- 外链缺口：IO-Link 协议与设备集成 → IO-Link 主站操作说明（外部）。
