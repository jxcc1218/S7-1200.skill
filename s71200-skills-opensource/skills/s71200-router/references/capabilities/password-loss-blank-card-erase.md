# 能力卡：丢密码唯一恢复路径 = 空卡擦除（删整个程序）

## R（原文引用）
> "在密码丢失或忘记密码时，可使用空传送卡访问受密码保护的 CPU。"（p99）
> "此时，STEP 7 将创建空传送卡。如果要创建空传送卡以便在丢失 CPU 密码后恢复，请从读卡器中移除传送卡。"（p102）
> "将传送卡插入 CPU 中……对 CPU 循环上电以评估存储卡……重启后，CPU 会对存储卡进行评估并将程序复制到 CPU 的内部装载存储器。"（p103，空卡评估路径为擦除内部装载存储器）
> ——《S7-1200 系统手册》V4.7，6.5 使用存储卡

## I（自述）
CPU 密码（保护机密 PLC 组态数据/访问等级）丢失后，手册给出的唯一恢复路径是**空传送卡**：读卡器上创建"传送"类型空卡 → 插入 CPU → 循环上电评估 → CPU 内部装载存储器被擦除、密码随之删除——**代价是整个程序被删除**（含 DB、工艺对象、设备组态），之后必须重新下载项目。两处硬约束：①卡必须包含 `__LOG__` 与 `crdinfo.bin` 隐藏文件，删了卡就废（p102 注意）；②复用旧卡前必须删 `S7_JOB.S7S` 及 SIMATIC.S7S 等旧作业文件。此操作与"复位为出厂设置"等效于清场，属于不可逆动作，执行前必须获得处置授权。

## A1（合成演练，含可复算数值）
原书未提供数值算例。合成演练：CPU 设了访问等级密码，密码持有人离职。步骤：空白卡制空传送卡（卡类型=传送，p102 步骤 1–4）→ 插入 CPU（RUN 则转 STOP，MAINT 闪烁）→ 循环上电 → 评估完成（RUN/STOP 绿黄交替→黄常亮+MAINT 闪）→ 取卡 → 内部装载存储器已空、密码已删 → 重新下载项目并重设密码。每步现象按 p103 表核对。

## A2（未来触发）
- 场景："密码忘了进不去 CPU 怎么办"；接手二手/遗留设备清场；安全处置授权评审。
- 语言信号：中"忘记密码／空传送卡／擦掉密码恢复"；英"lost password / blank transfer card / delete program to reset password"。
- 相邻区分：换件时的密码处置（卡还在手）→ cpu-swap-password-sdcard-disposal；经卡批量设/删密码（SET_PWD 作业，p107）→ 存储卡密码作业域；"不支持安全擦除"的数据残留问题 → no-secure-erase 卡。

## E（执行步骤）
1. 输入契约：CPU 型号、现象（在线提示密码保护）、授权状态（此操作删除程序，需负责人批准）。
2. 制空传送卡：空白卡（或清掉 S7_JOB.S7S/旧文件夹）→ STEP 7 读卡器属性 → 卡类型=传送 → **不装载程序**。
3. 插卡（断电/STOP 优先）→ 循环上电评估 → 观察按 p103 LED 序列。
4. 取卡 → 重启 → 确认内部装载存储器为空（无程序无密码）。
5. 重新下载项目、重设访问等级/机密数据密码。
6. 完成标准：CPU 恢复可下载状态且新密码生效；全程记录（不可逆操作留痕）。

## B（边界）
- 反场景：只是"在线连不上/不知道 IP"（不是密码问题 → emergency-ip）；密码在手只是要换策略（在线设/删，p953）。
- 手册口径：p103"将 CPU 设置为 RUN 模式之前，请取出传送卡"——评估完成后立即取卡，否则每次上电重复评估。
- 矛盾/勘误：B21——p109 固件更新路径把待删文件写成 S7_JOB.SYS，正确为 **S7_JOB.S7S**（p102/104/107 一致）；本卡按 .S7S 执行。
- 外链缺口：无。
