# 能力卡：功率预算三条前置约束（扩展上限 / 禁并联 / 非隔离 M 同电位）

## R（原文引用）
> "通信模块 (CM) 安装在 CPU 左侧。任何 CPU 最多可以连接 3 个通信模块。信号板 (SB)、通信板 (CB) 和电池板 (BB) 安装在 CPU 顶部。任何 CPU 最多可以连接 1 个信号板、通信板或电池板。"
> "务必确保 PLC 系统中的所有非隔离 M 端子都连接到同一个参考电位。"
> ——《S7-1200 系统手册》V4.7，p1153–1154

## I（自述）
双列减法开算之前有三条硬约束必须先过，否则算出的"差额"没有意义：
1. SM 数量上限按 CPU 型号（1211C=0 / 1212C=2 / 1214C、1215C、1217C=8，p1153 表）；
2. CM 最多 3 个（左侧），对 CP 同样适用——CM 与 CP 共享"左侧 3 个"的名额；
3. SB/CB/BB 三者**互斥共用 CPU 顶部一个板槽**，合计最多 1 个——比"每类最多 1 个"更严格：装了 BB 1297 电池板就不能再装 SB 信号板。
另外所有非隔离 M 端子必须接到同一参考电位，否则产生不可预测电流。

## A1（合成演练，含可复算数值）
原书未提供本条独立算例。合成演练：CPU 1214C + 8 SM + 3 CM + 1 SB + 1 BB。逐条检查：SM 8/8 ✓；CM 3/3 ✓；板槽 SB+BB = 2 > 1 ✗ → 必须二选一，修完清单（SB 或 BB 留一个）才允许进入双列减法。第二例：CPU 1212C + 3 SM → 3 > 2 ✗，先裁 1 个 SM。

## A2（未来触发）
- 场景：扩展选型时问"这几个卡能不能一起装"；画接线图时问"非隔离 M 端怎么接"；预算之前做可行性检查。
- 语言信号：中"最多装几个 CM／SB 和电池板能同时用吗／1212C 能挂几个模块／非隔离 M 接一起"；英"max CM count / SB and BB same slot / M terminals same potential"。
- 相邻区分：上限通过之后的功率计算 → power-budget-dual-column-procedure；扩展电缆条数限制 → expansion-cable-one-only；具体耗值 → 24v-consumption-quotas。

## E（执行步骤）
1. 输入契约：CPU 型号 + 模块清单（SM/CM/CP/SB/CB/BB 逐项）。
2. 三查：SM 数 ≤ 型号上限；CM+CP ≤ 3；SB/CB/BB 合计 ≤ 1。
3. 判停：任一超限 → 先修清单，未过三查不得开始预算计算。
4. 检查非隔离 M 端电位图：全部同电位（数据表标注"非隔离"的 24V 电源输入、SM 继电器线圈电源输入、非隔离模拟电源输入均在此列，p1153–1154）。
5. 完成标准：三查通过 + 电位结论明确，输出"可进入预算计算"或"超限项清单"。

## B（边界）
- 反场景：直接问"带不带得动"（上限检查只是预算的输入参数，结论仍要靠双列减法）；单条电缆限制（→expansion-cable-one-only）。
- 手册警告（p1154）："将非隔离 M 端子连接到不同参考电位会引起无法预测的电流……PLC 损坏或者 PLC 和设备异常运行"。
- 矛盾/勘误：无直接矛盾；注意 H2 结论（SB/CB/BB 三者互斥）来自 pE-22 交叉验证，比 p1153 正文"最多可以连接 1 个"的表述更严格，取舍从 H2。
- 外链缺口：故障安全 F 模块不在本上限口径的常规表内（附录 A 完全不含 F 模块规格，澄清清单 H1）。
