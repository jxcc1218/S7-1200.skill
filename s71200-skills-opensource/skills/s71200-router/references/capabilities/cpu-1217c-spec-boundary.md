# 能力卡：CPU 1217C 规格分界读数模板（1MHz HSC / 250KB 工作存储器 / 双端口）

## R（原文引用）
> "高速计数器 最多可组态 6 个……1 MHz（Ib.2 到 Ib.5）；100/180 kHz（Ia.0 到 Ia.5）；30/120kHz（Ia.6 到 Ib.1）。"（p1045）
> "用户存储器 工作 250 KB；负载 内置 4 MB，可用 SD 卡扩展……板载数字 I/O 14 点输入/10 点输出。"（p1044 表 A-92）
> "A.9.3 通信 CPU 1217C：端口数量 2，类型以太网，HMI 设备 4，编程设备 (PG) 1，连接数 预留 34 条，最多 68 条。"（p1046 表 A-95）
> ——《S7-1200 系统手册》V4.7，A.9 CPU 1217C

## I（自述）
CPU 1217C 是 S7-1200 标准系列的顶配分界，读规格时锁定三个标志性数字：①**1 MHz HSC**——仅 Ib.2–Ib.5（差分输入），其余输入 100/180 kHz 或 30/120 kHz；②**250 KB 工作存储器**（内置 4 MB 装载，SD 可扩展），M 区 8192 字节；③**2 个 PROFINET 端口**（其余 1211–1215C 只有 1 个），连接 34 预留/最多 68。配套：5V 预算 1600 mA/24V 传感器电源 400 mA（p1044）、板载 14DI/10DQ（MOSFET）+2AI/2AQ、脉冲输出 1 MHz（Qa.0–Qa.3）。用途：选型对比与"这 CPU 行不行"的秒级判定。

## A1（合成演练，含可复算数值）
原书未提供数值算例（本卡为查表型）。合成演练：需求"编码器 1 MHz A/B 计数 + 双网口分别接车间网与 HMI" → 1 MHz 落 Ib.2–Ib.5（表 11-9 四相同样 1 MHz，p455）✓；双端口 ✓ → 1217C 唯一满足。反向：只报"Ia.3 接 1 MHz 编码器" → Ia 段最高 100 kHz，超限，必须换接线到 Ib.2–Ib.5。

## A2（未来触发）
- 场景：选型对比；"1217C 和 1215C 差在哪"；高频计数/脉冲需求能否满足。
- 语言信号：中"1217C 规格／1MHz 计数／两个网口／250KB 工作存储器"；英"CPU 1217C specs / 1 MHz HSC / dual PROFINET ports"。
- 相邻区分：功率预算计算（5V/24V 减法）→ power-budget-dual-column-procedure（本卡只提供输入数值 1600/400）；连接资源核算（HMI 占几条）→ connection-budget（晋级卡，本卡给"34/68"基数）；其它 CPU 型号 → 附录 A 各节（A.5–A.8）。

## E（执行步骤）
1. 输入契约：需求清单（HSC 频率与引脚、存储器、网口数、脉冲输出）。
2. 逐项查 p1044–1046 表：HSC 分段频率、工作存储器 250 KB、端口数 2、连接 34/68、5V/24V 预算。
3. 判定：任一项不满足 → 换型或改需求（如编码器换接 Ib.2–Ib.5）。
4. 输出契约："需求项 | 1217C 规格 | 满足/不满足"对照表。
5. 完成标准：每项需求都有判定；规格值注明页码出处。

## B（边界）
- 反场景：问"带这些模块功率够不够"（→预算卡）；问"能接几台 HMI"（→连接预算卡，别拿 34/68 直接当 HMI 上限——HMI 每台占 2–3 条）。
- 手册口径：1 MHz 仅差分输入 Ib.2–Ib.5；正交模式会降速（p1045 脚注 1）；脉冲输出需 DC/DC/DC 型（继电器输出 CPU 需 SB，p997 脚注 2 同口径）。
- 矛盾/勘误：无；rejected 重复指针已按 canonical 并入本卡路由（destinations notes）。
- 外链缺口：无（附录 A 自足）。
