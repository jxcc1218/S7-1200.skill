# 能力卡：AINFO 字节 26–33 解析（RALRM 判定断路/溢出，16#0006/0007/0008 + aaabb000）

## R（原文引用）
> "32 和 33 定义错误类型的字：16#0000：预留；16#0001：短路；16#0002：欠压；16#0003：过压；16#0004：过载；16#0005：过温；16#0006：断线；16#0007：超出上限；16#0008：超出下限；16#0009：错误。……字节 28 和 29 包含负责该诊断的通道号的字。位模式 aaabb000，指示通道类型 (aaa) 和错误类型 (bb)。"
> ——《S7-1200 系统手册》V4.7，15.20 确定 SM 1231 模块的断路条件类型，p978

## I（自述）
当模拟量输入读到 32767 需要判定"断路还是溢出"时，手册给的唯一官方路径：诊断错误中断 OB → RALRM 指令 → 解析 AINFO 字节数组的 26–33 字节。字节含义：26/27=16#8000（PROFINet 相关标记）、28/29=通道号+类型（位模式 aaabb000：aaa 为通道类型 001=输入，bb 为错误类型 01=进入错误）、31=数据格式、**32/33=错误类型字**（0006 断线 / 0007 超上限 / 0008 超下限）。这些条件是模块级的，不分通道。前提：AINFO 用 ≥34 字节数组，F_ID 取诊断 OB 的 LADDR。

## A1（书中算例，可复算）
p978 官方示例：字节 26/27=16#8000 → Profinet 类型诊断；字节 28/29 → 通道 0 或模块；字节 30=16#28 → 二进制 001 01 000 = 输入通道 + 进入错误；字节 31=5（字格式）；字节 32/33=16#0007 → **超出上限**。全链复算一致。

## A2（未来触发）
- 场景：用户手里有诊断中断报文/已经抓了 AINFO 数组，要逐字节判读；程序里写了 RALRM 想确认 32/33 字节含义。
- 语言信号：中"AINFO 怎么解析／字节 32 是 0006 什么意思／断线还是超量程"；英"AINFO bytes 32 33 / RALRM break detection / 0x0006 wire break"。
- 相邻区分：**手里只有 32767 这个值、没有报文** → 32767-ambiguity-resolution（晋级卡，本卡让路并互为近邻负例）；RTD 量程换算 → rtd-range-and-32767；TINFO/OB 启动信息不在本卡范围（D7 缺口）。

## E（执行步骤）
1. 输入契约：AINFO 字节数组（≥34 字节）；缺数组先指导用户在诊断 OB 中捕获，不得凭空判读。
2. 检查字节 26/27 = 16#8000（确认 PROFINET 相关诊断）。
3. 解析字节 28/29：通道号 = 位模式右移 3 位；进入/离开错误 = bb 位（01 进入/10 离开）。
4. 读字节 32/33 组合字：0006=断线，0007=超上限，0008=超下限（对照 0001–0005/0009 其他类型）。
5. 输出契约：一行结论"通道 n（输入）发生【断线/超上限/超下限】（进入/离开）错误"。
6. 自查：判定结果须与通道当前 32767/−32768 状态一致（0007 ↔ 32767，0008 ↔ −32768）。

## B（边界）
- 反场景：没有中断报文只有异常值 → 32767 晋级卡；问模块级诊断为什么"不分通道"→ 本卡 R 段已答（条件仅适用于模块）。
- 手册缺口：TINFO/AINFO 完整语义本手册不闭环（澄清清单 D7），仅字节 26–33 有官方解析，其余字段需 STEP 7 在线信息系统。
- 矛盾/勘误：MLEN=0 时按 AINFO 可容纳量接收（p305）；目标区过短时 RALRM 无法返回完整信息（p306）——数组太小不报错但字段不完整。
- 外链缺口：非 SM 1231 设备的 AINFO 布局 → STEP 7 在线信息系统（D7）。
